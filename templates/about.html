About ThreatCast Defense Platform

ThreatCast is a unified, next-generation network traffic analysis and simulated threat detection platform, designed for speed and clarity in forensic investigation and real-time monitoring. Developed by Cybersecurity students of Royal College of Engineering and Technology

Core Mission

To provide clear, actionable intelligence from high-volume network traffic. We prioritize immediate identification of zero-day exploits and pattern-based attacks.

Unified Analysis

Integrate data streams from multiple sources, including simulated PCAP captures, IP Detail Records (IPDR), and targeted IP range sweeps for comprehensive coverage. Detection relies on 10,000+ unique signature patterns.

Real-time Monitoring

Utilizing simulated concurrent processing, the platform offers a low-latency view of live traffic, ensuring timely intervention against developing threats.

Technology & Architecture

Backend Engine

  • Python & Flask: Robust web framework.
  • Multi-threading: For simulated concurrent traffic generation.
  • TrafficEngine: Custom core logic for packet and threat simulation.

Frontend Interface

  • HTML5/CSS3: Structure and professional dark theme.
  • RESTful API: For communication between client and server.
  • Custom JavaScript: Real-time data fetching and rendering.

Hybrid Rulebase and Dataset Integration

The Sentinel-X Hybrid Detection System (HDPS) is powered by a massive, integrated set of signatures to ensure comprehensive coverage:

  • Core High-Fidelity Rules: 10+ rule-engine signatures targeting critical attacks (SQLI, RCE, LFI/RFI, Web Shell Upload, etc.).
  • Dataset 2000 Integration: Simulates the integration of approximately 1,000 patterns (queries/URLs) used for training the Machine Learning component.
  • Realistic Malicious Dataset (5000+): Integrates 5,000+ unique, realistic malicious patterns (phishing, C2, trojans, ransomware payloads) to serve as a high-confidence threat feed, directly improving the attack simulation diversity.
  • ML Fallback: Utilizes a simulated ML classifier (XGBoost/LightGBM) to detect obfuscated or novel payloads not caught by the rule-first engine, driving up the HTS (Hybrid Threat Score).
